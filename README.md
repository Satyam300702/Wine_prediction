🍷 Wine Prediction Web App

This is a Machine Learning web application that predicts the class of wine based on its chemical properties. The app is built using Python, matplotlib, Seaborn, Scikit-learn, and Streamlit.
------------------------------------------------------------------------------------------------------------------------------------------------
Features

Predicts wine classes (Class 0, Class 1, Class 2) using a Gradient Boosting Classifier.

Provides prediction probabilities for each class.

Allows interactive input for all 13 wine features:

Alcohol, Malic Acid, Ash, Alcalinity of Ash, Magnesium, Total Phenols, Flavanoids, Nonflavanoid Phenols, Proanthocyanins, Color Intensity, Hue, OD280/OD315 of diluted wines, Proline.

Simple and user-friendly web interface using Streamlit.
------------------------------------------------------------------------------------------------------------------------------------------------
Dataset

Uses the classic Wine dataset from Scikit-learn:

178 samples

13 features

3 classes

Dataset source: UCI Machine Learning Repository
------------------------------------------------------------------------------------------------------------------------------------------------
Model

Gradient Boosting Classifier

Achieved 100% accuracy on the test set.

Cross-validated score: 0.97
